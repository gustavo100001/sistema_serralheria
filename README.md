   -- Sistema de gerenciamento para serralheria --

   Versão v0.2   -Ainda não finalizada-

. Sobre o projeto: 
          Trata-se de um sistema que busca facilitar procedimentos de execução de trabalho em uma serralheria. 

. Tecnologias usadas:
          Nessa versão do codigo(v0.2) apenas o Python 3.12

. O faz essa versão (v0.2):
          O usuário poderá conferir ferramentas que serão usadas na obra, organizar e salvar tamanhos de cortes e conferir quais foram cortados, e fazer orçamento que se digita os materiais, preços e no final é calculado o preço com a mão de obra.

. Novidades no codigo:
         Cada funcionalidade agora é uma função separada, fazendo com que o codigo rode apenas a função que é chamada.
         Agora os valores inseridos em que quando se pede o preço e o tamanho em centimetros passam por validação para evitar erro.
         O sistema inicia pedindo login ou cadastro.

. Melhorias em futuras versões:
         Dados salvos em banco de dados, com SQL .
         Mais funcionalidades como algum uso com os dados registrados, por exemplo: somar centimetros cortados, quantas barras de metal, escolher porcentagem da mão de obra e inserir mais ferramentas que serão levadas a obra.
